# MPESA Crypto Wallet 💰⚡

## 📌 Project Description

MPESA Crypto Wallet is a **realtime fintech simulation system** that combines **mobile money (M-Pesa style transactions)** and **cryptocurrency wallet operations** into a single platform.

The system demonstrates **Object-Oriented Programming (OOP)**, **Data Structures & Algorithms (DSA)**, and backend engineering principles through a secure and scalable transaction processing engine.

---

## 🚀 Features

* 👤 User registration and authentication
* 💳 Digital wallet creation
* 💸 Send & receive money (M-Pesa style)
* 🪙 Crypto wallet simulation (BTC, ETH, etc.)
* 📊 Transaction history tracking
* ⚡ Realtime transaction updates (WebSocket-ready)
* 🔁 Transaction fees & processing logic
* 🔐 Secure balance validation system

---

## 🏗️ System Architecture

* Backend: PHP (Yii2 / OOP PHP)
* Database: MySQL
* Realtime Layer: WebSockets / AJAX polling
* Design: MVC + Service Layer Architecture

---

## 🧠 Concepts Applied

### Object-Oriented Programming (OOP)

* Encapsulation (wallet balance protection)
* Inheritance (CryptoWallet extends Wallet)
* Polymorphism (different transaction types)
* Abstraction (payment interfaces)

### Data Structures & Algorithms (DSA)

* HashMap → wallet lookup
* Queue → transaction processing
* Stack → rollback system
* Sorting → transaction history
* Searching → user transactions
